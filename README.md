# Pusheen Gembul Corner 🐾

A simple and fun web application that fetches and displays random cat pictures using [TheCatAPI](https://thecatapi.com/).

## Features

*   **Random Cat Pictures:** Get a new adorable cat picture with a single click!
*   **Loading Indicators:** Shows a spinner while fetching the image.
*   **Responsive Design:** Works well on both desktop and mobile devices.

## How to Run

1.  Clone this repository to your local machine.
2.  Open `index.html` in your web browser. No server setup is required!

## API Key (Optional)

The application uses TheCatAPI to fetch images. For basic usage, an API key is not required. However, if you plan to use it heavily or want access to more advanced features, you can get a free API key:

1.  Sign up at [TheCatAPI](https://thecatapi.com/signup).
2.  Open `script.js`.
3.  Find the `const apiKey = "";` line and paste your key between the quotes.
